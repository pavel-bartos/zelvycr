# Kontrola faktů pro klienta

Seznam všech údajů v nových textech, které potřebují potvrzení chovatele (Jiřího Haltufa),
než se text označí `schvaleno`. Formát: **údaj → zdroj → otázka pro klienta.**

Jiří díky tomu nemusí číst celé texty — projde jen tenhle seznam a odpoví na otázky.
Výjimka: texty želvy pardálí a kloubnaté jsou nové z veřejných zdrojů, ty je potřeba
přečíst celé (viz `druhy.md`, značka `[KE KONTROLE KLIENTEM]`).

- `druhy.md` — fakta o druzích
- `clanky.md` — fakta v článcích průvodce
