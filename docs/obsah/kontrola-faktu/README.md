# Kontrola faktů pro klienta

Seznam údajů v nových textech, které nejsou z původního webu. Rozdělený do dvou kategorií
podle toho, co od klienta potřebujeme:

- **[A-potvrdit.md](A-potvrdit.md) — dohledáno a navrženo, potřebujeme POTVRDIT.**
  Informace jsme dohledali z renomovaných zdrojů (veterinární školy, odborné care sheety,
  předpisy) a navrhli znění. Klient je projde a potvrdí, že sedí s jeho praxí – nebo opraví.
- **[B-dodat.md](B-dodat.md) — nevíme, musí DODAT klient.**
  Informace, které z internetu dohledat nejdou (vlastní tvrzení chovatele, termíny, počty,
  fotky). Bez klienta je nemáme.

Formát v obou: údaj → (zdroj / proč) → otázka nebo co potřebujeme.

Texty druhů pardálí a kloubnaté jsou celé nové z veřejných zdrojů – projděte je celé
(viz A-potvrdit, oddíl Druhy).
